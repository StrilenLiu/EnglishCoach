# 系统级依赖（不是 Python 包，pip 装不了，需用系统包管理器或 conda 安装）
# System-level dependencies. These are NOT Python packages: pip cannot install
# them, so use your system package manager or conda.
#
# Linux 编译必需 / Required to build on Linux:
#   binutils  —— 提供 objdump，PyInstaller 用它分析二进制依赖；缺少会在打包
#                阶段报 "On Linux, objdump is required"
#                Provides objdump, which PyInstaller uses to analyse binary
#                dependencies; without it packaging fails with
#                "On Linux, objdump is required"
#   curl      —— 下载 Argos 中英离线翻译模型；缺少则模型打不进产物，
#                用户端离线翻译失效
#                Downloads the Argos offline translation models; without it
#                the models are missing from the build and offline
#                translation fails for users
#   tar       —— 打包最终产物 / packages the final archive
#
#       conda install -y binutils curl tar
#       sudo apt install -y binutils curl tar      # Debian / Ubuntu
#       sudo dnf install -y binutils curl tar      # Fedora / RHEL
#       sudo pacman -S binutils curl tar           # Arch
#       sudo apk add binutils curl tar             # Alpine
#
#   Build Linux.sh 在开始安装依赖【之前】会统一检查这些命令，缺失时依次尝试
#   conda、apt、dnf、yum、pacman、apk、zypper 自动安装，都失败才退出并打印
#   上述命令 —— 不会等到编译中途才失败。
#   Build Linux.sh checks all of these BEFORE installing any dependency and
#   tries conda, apt, dnf, yum, pacman, apk and zypper in turn, only exiting
#   with the commands above if every attempt fails — so the build never dies
#   halfway through for a missing system tool.
#

# For the Qt runtime libraries needed on Linux, see Troubleshooting in README.
